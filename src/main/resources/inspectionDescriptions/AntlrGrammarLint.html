Reports grammar simplifications found by the antlr4-xl linter, most with a quick fix:
  • lint1: a rule with a single child, which can be inlined where it's used
  • lint2: duplicate alternatives
  • lint3: rules that are never used (report only)
  • lint4: unnecessary parentheses
  • lint5: suffixes that can be merged, such as ( 'a'+ )? to 'a'*
  • lint6: a start rule that doesn't end with EOF (report only)
  • lint7: empty alternatives (report only)

"Fix all grammar lint findings in file" applies every fix, repeating until nothing changes.

Grammars with syntax errors aren't linted.
